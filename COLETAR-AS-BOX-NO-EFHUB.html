Coletar as box no efHub

pelo Console do Chrome — sem depender de mim, e sem varrer as 1.953 páginas do índice

Por que este caminho e não o índice.
O índice do efHub tem 46.862 cartas em 1.953 páginas, ordenado por nota. Achar carta nova ali é procurar agulha. A lista de box tem 600 entradas e já vem da mais recente para a mais velha — e cada box entrega os números das cartas dela de uma vez. Uma box nova aparece na primeira página.
O efHub atualiza uma vez por semana.
Medido em 17/08: as coletas deles são 13/08, 06/08, 30/07, 23/07… Box lançada hoje no jogo só aparece aqui na virada seguinte. Se você rodar e não achar a box nova, não é defeito — é que eles ainda não coletaram.

Passo 1 — abrir o efHub

  1. Abra o efhub.com numa aba
  2. Aperte F12 e clique na aba Console
  3. Se aparecer um aviso vermelho pedindo para digitar algo, digite allow pasting e dê Enter

Passo 2 — colar o bloco

Cole no Console e dê Enter. Leva uns 4 minutos (600 box, com pausa entre cada uma para o site não fechar a porta). Não feche a aba enquanto roda.

(async function(){
 const PAUSA = 350;
 const packs = []; let pg = 1;
 console.log('%cCOLETA DAS BOX DO efHUB - NAO FECHE ESTA ABA','background:#f0a531;color:#000;font-weight:700;padding:3px 8px');
 while (pg <= 80) {
  const r = await fetch('/api/public/packs?page=' + pg, {credentials:'include'});
  if (!r.ok) { console.log('a lista de box parou no HTTP ' + r.status); break; }
  const j = await r.json(); const p = j.packs || [];
  if (!p.length) break;
  packs.push(...p);
  if (!j.hasMore) break;
  pg++;
 }
 console.log('   ' + packs.length + ' box. Agora as cartas de cada uma...');
 const out = {}; let i = 0, erros = 0;
 for (const p of packs) {
  i++;
  try {
   const r = await fetch('/pt-BR/packs/' + p.slug, {credentials:'include'});
   const h = await r.text();
   const ids = [...new Set([...h.matchAll(/player_cards\/(\d+)_/g)].map(m => m[1]))];
   out[p.slug] = {nome: p.name, quantas_o_site_diz: p.playerCount,
                  datapack_do_efhub: p.date, cartas: ids};
  } catch (e) {
   erros++;
   out[p.slug] = {nome: p.name, quantas_o_site_diz: p.playerCount,
                  datapack_do_efhub: p.date, cartas: [], erro: String(e).slice(0,80)};
  }
  if (i % 25 === 0) console.log('   ' + i + '/' + packs.length + ' box · erros ' + erros);
  await new Promise(s => setTimeout(s, PAUSA));
 }
 const pacote = {
   o_que_e: 'as box do efHub: o nome, os ids das cartas de cada uma, e a data do datapack',
   ATENCAO: 'datapack_do_efhub NAO e a data de lancamento da box. E a data da coleta semanal do efHub. A data de lancamento sai do NOME da box.',
   fonte: 'efhub /api/public/packs + /pt-BR/packs/<slug>',
   colhido_em: new Date().toISOString(),
   quantas_box: Object.keys(out).length,
   erros: erros,
   box: out
 };
 const b = new Blob([JSON.stringify(pacote)], {type:'application/json'});
 const a = document.createElement('a');
 a.href = URL.createObjectURL(b); a.download = 'efhub_boxes.json';
 document.body.appendChild(a); a.click(); a.remove();
 console.log('%cPRONTO - ' + Object.keys(out).length + ' box baixadas em efhub_boxes.json',
             'background:#22c58b;color:#000;font-weight:700;padding:3px 8px');
 console.log('Mande o arquivo para a pasta do motor e rode ENTRAR-COM-AS-BOX.bat');
})();

Passo 3 — o arquivo

  1. No fim ele baixa sozinho o efhub_boxes.json (vai para a sua pasta de Downloads)
  2. Arraste o arquivo para dentro da pasta truefootball-motor-v6
  3. Dê dois cliques em ENTRAR-COM-AS-BOX.bat
O que ele NÃO faz, de propósito.
A data que o efHub dá em cada box (datapack_do_efhub) é a data da coleta semanal deles, não o lançamento da box. A "Summer Transfer 17 Aug '26" vem com data 13/08. Ela não entra como data de lançamento — essa continua saindo do nome da box.
