As colunas que o efHub preenche

Quatro colunas novas. Só acrescenta — não apaga nem muda nada.

Por que estas vão para o banco e não para um arquivo.
O unificar_base.py já lê o pé ruim e a progressão — esses o programa grava direto no arquivo que ele lê. Idade, lesão, forma, condição, corpo e estilo de jogo da IA ele não lê. Em vez de mexer no motor, elas vão para o banco, que é o destino de todo mundo de qualquer jeito.

O que entra

colunao que éde onde vem, no efHub
formaa forma do jogadorform
condicaoa condiçãocondition
corpoas 12 medidas, na nossa ordemheight + as 11 do playerModel
level_capaté que nível a carta sobelevelCap

As outras já existem desde hoje de manhã: idade, lesao, pe_ruim_uso, pe_ruim_precisao, estilo_ia, maximo, nota_maxima_tela, visto_na_casca.

A ordem das 12 medidas do corpo — medida em 14/08, está no CORPO_CHAVES.json: 
0 altura        (height — fica FORA do playerModel)
1 coxa          thighSize          7 comprPerna    legLength
2 panturrilha   calfSize           8 comprBraco    armLength
3 cintura       waistSize          9 comprPescoco  neckLength
4 peito         chestMeasurement  10 largOmbro     shoulderWidth
5 tamBraco      armSize           11 altOmbro      shoulderHeight
6 tamPescoco    neckSize

O passo a passo

  1. Abra o editor: supabase.com → SQL Editor
  2. Clique no botão verde.
  3. No editor: Ctrl+A, Ctrl+V, Ctrl+Enter.
  4. Volte para a pasta e dê dois cliques no ENTRAR-COM-O-EFHUB.bat.

-- ============================================================
--  AS COLUNAS QUE O efHUB PREENCHE  ·  16/08/2026
--  So acrescenta. Nao apaga nada, nao muda nenhum valor.
-- ============================================================

alter table cards_base add column if not exists forma      int;
alter table cards_base add column if not exists condicao   int;
alter table cards_base add column if not exists corpo      jsonb;
alter table cards_base add column if not exists level_cap  int;

comment on column cards_base.corpo is
  'As 12 medidas do corpo na ordem do CORPO_CHAVES.json (14/08): altura, coxa, panturrilha, cintura, peito, tamBraco, tamPescoco, comprPerna, comprBraco, comprPescoco, largOmbro, altOmbro. A altura vem do campo height e NAO esta entre as do playerModel.';

comment on column cards_base.level_cap is
  'Ate que nivel a carta sobe. Vem do levelCap do efHub.';

-- ------------------------------------------------------------
-- A visao do que o efHub ja respondeu, por campo
-- ------------------------------------------------------------
create or replace view o_que_o_efhub_trouxe as
select 'idade'            as campo, count(*) as cards from cards_base where idade is not null
union all select 'lesao',            count(*) from cards_base where lesao is not null
union all select 'estilo de jogo IA', count(*) from cards_base where estilo_ia is not null
union all select 'pe ruim: uso',      count(*) from cards_base where pe_ruim_uso is not null
union all select 'pe ruim: precisao', count(*) from cards_base where pe_ruim_precisao is not null
union all select 'forma',             count(*) from cards_base where forma is not null
union all select 'condicao',          count(*) from cards_base where condicao is not null
union all select 'corpo',             count(*) from cards_base where corpo is not null
union all select 'progressao',        count(*) from cards_base where level_cap is not null
order by cards desc;

comment on view o_que_o_efhub_trouxe is
  'Quanto de cada campo o efHub ja preencheu. Serve para conferir a coleta sem abrir arquivo nenhum.';
⛔ O que este comando NÃO faz
Não apaga coluna, não apaga linha, não muda valor nenhum que já esteja lá. Só cria coluna que ainda não existe — se você rodar duas vezes, a segunda não faz nada.
