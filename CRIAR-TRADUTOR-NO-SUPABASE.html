Criar o tradutor no Supabase

É a única parte que precisa de você. Depois disto, é duplo clique.

O que este comando faz — e o que ele NÃO faz.
  • Cria a tabela traducao, que guarda como cada fonte chama cada coisa.
  • Acrescenta cinco colunas na tabela de funções: o código fixo e os rótulos.
  • Não apaga nada. Não altera nenhuma linha de pontuação. Não troca nenhuma chave. A chave das funções continua sendo o nome, exatamente como está hoje.

O passo a passo

  1. Abra o editor: supabase.com → SQL Editor
  2. Clique no botão verde aqui embaixo — o comando vai para a área de transferência.
  3. Clique dentro do editor, aperte Ctrl+A e depois Ctrl+V (isso apaga o que estiver lá e cola o nosso).
  4. Aperte Ctrl+Enter para rodar.
  5. Se aparecer uma janela pedindo confirmação, é normal — ela aparece sempre que o comando cria ou altera tabela. Pode confirmar.
  6. Deve aparecer Success. No rows returned. É isso.
  7. Volte para a pasta e dê dois cliques no SUBIR-TRADUTOR.bat.

O comando, se você quiser ler antes

-- ============================================================
--  O TRADUTOR  ·  16/08/2026
--  So acrescenta. Nao apaga nada, nao troca chave nenhuma.
-- ============================================================

-- 1) A tabela de traducao: como cada fonte chama cada coisa.
create table if not exists traducao (
  assunto        text        not null,
  chave          text        not null,
  fonte          text        not null,
  como_chama     text,
  medido         boolean     not null default false,
  observacao     text,
  atualizado_em  timestamptz not null default now(),
  primary key (assunto, chave, fonte)
);

comment on table traducao is
  'Como cada fonte chama cada coisa. A chave e SEMPRE a nossa; o resto e rotulo. Sobe pelo SUBIR-TRADUTOR.bat, a partir do CHAVES.json. Ordem do Luis 16/08: "tem que ter tipo um tradutor nesse meio".';

create index if not exists traducao_assunto_idx on traducao (assunto);
create index if not exists traducao_como_idx    on traducao (como_chama);

-- 2) As colunas novas da tabela de funcoes.
--    ⛔ A COLUNA `nome` CONTINUA SENDO A CHAVE. Nao mexemos nela:
--       tres tabelas apontam para ela com apagamento em cascata, e trocar
--       agora apagaria 11.115 linhas de resultado, 936 de molde e 144 de estilo.
alter table funcoes add column if not exists codigo         text;
alter table funcoes add column if not exists rotulo         text;
alter table funcoes add column if not exists rotulo_curto   text;
alter table funcoes add column if not exists grupo          text;
alter table funcoes add column if not exists sigla_posicao  text;

comment on column funcoes.codigo is
  'O codigo fixo da funcao, congelado em 14/08 no CHAVES.json. ESTE nunca muda, nem quando o nome de tela mudar. E ele que vai virar a chave quando o Luis autorizar a troca.';
comment on column funcoes.rotulo is
  'O nome que aparece no card hoje. Decisao do Luis, 15 e 16/08.';

create unique index if not exists funcoes_codigo_uk on funcoes (codigo) where codigo is not null;
Por que isto não pode ir no duplo clique junto com o resto.
Criar e alterar tabela só se faz por comando direto no banco, e o programa da pasta não tem esse caminho — ele só sabe gravar linha. Por isso esta parte é sua, uma vez só. Depois disto, o SUBIR-TRADUTOR.bat preenche tudo sozinho e confere no fim.
