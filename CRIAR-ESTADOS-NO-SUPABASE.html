O passo a passo

  1. Abra o editor: supabase.com → SQL Editor
  2. Clique no botão verde.
  3. No editor: Ctrl+A, Ctrl+V, Ctrl+Enter.
  4. Se pedir confirmação, pode confirmar.
  5. Volte para a pasta e dê dois cliques no ESTADOS.bat.

O comando

-- ============================================================
--  OS QUATRO ESTADOS DE CADA DADO  ·  16/08/2026
--  So acrescenta. Nao apaga nada, nao muda nenhum valor.
-- ============================================================

-- 1) A coluna. Ao lado da fonte_de_cada_campo, que ja existe.
alter table cards_base add column if not exists estado_de_cada_campo jsonb;

comment on column cards_base.estado_de_cada_campo is
  'Para cada campo, uma de quatro palavras: valor | zerado | nao_se_aplica | nao_sei. Ordem do Luis 16/08: "nao pode haver essa confusao" entre zero e nao sei. So o nao_sei e pendencia de coleta.';

create index if not exists cards_base_estado_gin on cards_base using gin (estado_de_cada_campo);

-- 2) A visao que conta a falta DE VERDADE — so o "nao sei".
--    Substitui a conta por campo vazio, que inflava seis vezes.
create or replace view falta_de_verdade as
select e.key   as campo,
       count(*) as cards
from cards_base c,
     lateral jsonb_each_text(c.estado_de_cada_campo) e
where e.value = 'nao_sei'
group by e.key
order by cards desc;

comment on view falta_de_verdade is
  'O que falta coletar, de verdade. Conta so o estado nao_sei. Em 16/08 a conta antiga, por campo vazio, dizia 1.727 cartas sem impeto quando o numero real era 273.';

-- 3) A mesma coisa, mas carta a carta — para o motor de atualizacao consumir.
create or replace view o_que_puxar as
select c.card_id,
       c.nome,
       c.ovr,
       e.key as campo
from cards_base c,
     lateral jsonb_each_text(c.estado_de_cada_campo) e
where e.value = 'nao_sei';

comment on view o_que_puxar is
  'A lista de compras do motor de atualizacao: qual carta, qual campo. Uma linha por buraco de verdade.';
A conta que motivou isto.
Contando "campo vazio" como falta, o ímpeto dava 1.727 cartas faltando. O número real é 273 — as outras são 1.151 cartas velhas que o jogo não dá ímpeto (não é buraco, é resposta) e 303 que já têm. Inflava seis vezes. E o mesmo erro foi cometido três vezes em 24 horas: no estilo de jogo da IA, no corpo e no ímpeto.
