Criar a coluna da casca

Um comando. É a última coisa que falta para o banco virar a fonte única.

POR QUE ISTO EXISTE
O conferir das 15h16 deu bloco 3 vazio — o banco e a pasta concordam em tudo que os dois têm. Sobrou um campo só no bloco 2: 

2) SO A PASTA TEM - o que voce PERDE ao baixar
   maxOvr    2.785 cartas
O maxOvr é a pontuação máxima resgatada das 22 cascas de HTML. Não existe coluna para ele no banco — então baixar apagaria os 2.785.

E por que não pode ir na coluna que já existe

A tabela já tem nota_maxima_tela. O nome engana: ela guarda outra coisa.

colunaquem escreveo que é
nota_maxima_telaentrar_com_o_efhub.py o overallRating que o efHub devolve
a novasubir_base.py o maxOvr que a casca mostrava
Medido em 16/08 15h13, carta por carta: 
cartas com os DOIS numeros ..... 2.785
   DISCORDAM ................... 2.444    <- 88%

33185   a pasta diz 82,51   o banco diz 81,0
São duas medidas diferentes, não uma repetida. Juntar as duas numa coluna só apagaria 2.444 números sem ninguém ver. Por isso ficam lado a lado até você decidir qual vale — é o item 22 do CONSERTOS-PENDENTES.html.

O comando

-- ============================================================
--  A COLUNA DA CASCA  -  16/08/2026
--  So ACRESCENTA. Nao apaga, nao renomeia, nao toca em nenhuma
--  linha de pontuacao. Rodar duas vezes nao faz mal.
-- ============================================================

alter table public.cards_base
  add column if not exists pontuacao_maxima_da_casca numeric;

comment on column public.cards_base.pontuacao_maxima_da_casca is
  'O maxOvr resgatado das 22 cascas de HTML pelo RESGATAR-DA-TELA. NAO e a mesma coisa que nota_maxima_tela, que guarda o overallRating do efHub: medido em 16/08, os dois discordam em 2.444 de 2.785 cartas. As duas convivem ate o Luis decidir qual e a pontuacao maxima de verdade.';

-- confere: tem que voltar uma linha
select column_name, data_type
  from information_schema.columns
 where table_name = 'cards_base'
   and column_name = 'pontuacao_maxima_da_casca';

O passo a passo

  1. Abra o editor de SQL do Supabase: supabase.com/dashboard → SQL Editor
  2. Clique no botão verde aí em cima e cole no editor.
  3. Run. A última consulta tem que devolver uma linha: pontuacao_maxima_da_casca | numeric
  4. Volte na pasta e rode o FECHAR-O-CICLO.bat de novo.
  5. Se os blocos 2 e 3 vierem vazios, rode o BAIXAR-BASE.bat — e o banco passa a mandar.
✅ O NOME NOVO SEGUE A PALAVRA NOVA
A coluna nasce como pontuacao_maxima_da_casca, não "nota". As colunas antigas continuam com o nome que têm — trocar nome de coluna é trocar chave, e chave não se troca por causa de rótulo. Mas o que nasce hoje já nasce certo.
