Por que existe o visto_na_casca.
Só para as 1.836 cartas que aparecem numa casca original dá para dizer "conferi e não tem". Para as outras, campo vazio é não sei — ninguém puxou.

É a sua ordem de 15/08: "não ter não significa que você não achou. Se você pesquisou e não tem, é porque NÃO TEM — aí é zero. Agora se você NÃO ACHOU, é outra coisa."

Por que duas colunas para lesão e pé ruim

As cascas antigas guardam palavra; o dado novo guarda número. Medido nas 2.785 cartas:

lesao   'Média' 944 · 'Baixa' 430 · 'Alta' 411   e tambem   1: 78 · 0: 39 · 2: 19
wfu     'Raramente' 1004 · 'Ocasionalmente' 617 · 'Frequentemente' 164
                                                e tambem   1: 73 · 2: 40 · 0: 16 · 3: 7
wfa     'Média' 877 · 'Baixa' 542 · 'Alta' 366  e tambem   2: 86 · 1: 78 · 3: 19 · 0: 4

A tabela que traduz está dentro do código da tela, e só resolve uma das três:

PR_ROT_Q = ["Baixa","Média","Alta","Muito alta"]      -> wfa: bate exato
PR_ROT_F = ["Quase nunca","Raramente","Ocasionalmente","Regularmente"]
             -> wfu: 'Raramente' e 'Ocasionalmente' batem.
                'Frequentemente' NAO EXISTE nessa tabela.
lesao    -> nao existe tabela nenhuma.
⛔ Onde não bate exato, fica em branco — não inventado.
A coluna _bruto guarda a palavra do jeito que estava. A coluna sem sufixo só recebe número quando a tradução é exata. Traduzir no chute — dizer que "Frequentemente" é 3 porque parece — é a mesma classe de erro que a reforma inteira está caçando. Fica como pendência, para ser medido no jogo.

O passo a passo

  1. Abra o editor: supabase.com → SQL Editor
  2. Clique no botão verde aqui embaixo.
  3. No editor: Ctrl+A, Ctrl+V, Ctrl+Enter.

alter table cards_base add column if not exists idade                  int;
alter table cards_base add column if not exists lesao_bruto            text;
alter table cards_base add column if not exists lesao                  int;
alter table cards_base add column if not exists pe_ruim_uso_bruto      text;
alter table cards_base add column if not exists pe_ruim_uso            int;
alter table cards_base add column if not exists pe_ruim_precisao_bruto text;
alter table cards_base add column if not exists pe_ruim_precisao       int;
alter table cards_base add column if not exists mestre                 text;
alter table cards_base add column if not exists maximo                 jsonb;

comment on column cards_base.visto_na_casca is
  'A carta aparece numa casca original (encaixe_B_v16x/v171). SO para estas um campo vazio significa "conferido, nao tem". Para as outras, vazio e NAO SEI. Ordem do Luis, 15/08.';

comment on column cards_base.metadado_tela_de_onde is
  'De qual arquivo veio cada um dos oito campos, com a data, e se o arquivo e FONTE (casca original) ou COPIA PROPAGADA (saida que o proprio sistema gerou).';

comment on column cards_base.lesao_bruto is
  'A palavra como estava na casca. As cascas antigas guardam palavra, o dado novo guarda numero, e NAO EXISTE tabela que traduza lesao. Enquanto nao for medido no jogo, a coluna `lesao` fica vazia — traduzir no chute e inventar dado.';

comment on column cards_base.pe_ruim_uso_bruto is
  'A palavra como estava na casca. `Raramente` e `Ocasionalmente` batem com o PR_ROT_F da tela (1 e 2). `Frequentemente` NAO existe naquela tabela — fica sem numero ate ser medido.';

-- ------------------------------------------------------------
-- A visao do que sobrou sem traducao: a lista para medir no jogo
-- ------------------------------------------------------------
create or replace view palavra_sem_numero as
select 'lesao'            as campo, lesao_bruto            as palavra, count(*) as cards
  from cards_base where lesao_bruto is not null and lesao is null
  group by 1,2
union all
select 'pe_ruim_uso',      pe_ruim_uso_bruto,      count(*)
  from cards_base where pe_ruim_uso_bruto is not null and pe_ruim_uso is null
  group by 1,2
union all
select 'pe_ruim_precisao', pe_ruim_precisao_bruto, count(*)
  from cards_base where pe_ruim_precisao_bruto is not null and pe_ruim_precisao is null
  group by 1,2
order by cards desc;

comment on view palavra_sem_numero is
  'As palavras das cascas antigas que nenhuma tabela traduz. Cada linha e uma coisa para o Luis conferir no jogo uma vez so — depois vira traducao e nunca mais se pergunta.';
